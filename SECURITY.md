# Security Policy

## Reporting Vulnerabilities

If you discover a potential security vulnerability in this plugin, please do NOT create a public GitHub issue.

Instead, please report security concerns directly to the project maintainers or security contacts via email.

### What to Include in a Vulnerability Report

- Description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept script to reproduce the issue.
- Impacted versions of the plugin and Hyperledger Besu.

### Disclosure Policy

- Security reports will be acknowledged within 48 hours.
- Maintainers will work promptly to investigate and patch confirmed vulnerabilities before public disclosure.
