# Hyperledger Code of Conduct

The Hyperledger Foundation is committed to providing a welcoming and inspiring community for all.

We expect all contributors, maintainers, and community participants to follow the [Hyperledger Code of Conduct](https://toc.hyperledger.org/governing-documents/code-of-conduct.html).

### Summary of Principles

- **Be respectful:** Respect different backgrounds, opinions, and perspectives.
- **Collaborate openly:** Focus on what is best for the community and open-source project.
- **Gracefully accept constructive feedback:** Learn from community discussions and peer reviews.
